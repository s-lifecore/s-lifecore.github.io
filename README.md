## ambient/ について
　BGMに合わせて9種類のビジュアルシーン（フローフィールド・リサジュー・アトラクタ・星座・マンダラ・プラズマ・Boids・折り鶴・トンネル）が自動で切り替わるアンビエント映像体験です。マウス/タッチ操作でインタラクションできます。<br>
　[https://s-lifecore.github.io/ambient/](https://s-lifecore.github.io/ambient/)<br>
